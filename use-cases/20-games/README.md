# Games and simulations

A world that changes when time passes or a player acts.

## Tools

- pygame or arcade for a 2D game
- A pure function from state and action to the next state, which you can test without a window

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Move the player up, and leave the position unchanged for a second unknown action.
3. Keep the change small enough to finish in one sitting.

## Where it sits
