# Desktop, terminal, and mobile UI

A window, a terminal screen, or a small mobile app that a person operates.

## Tools

- Tkinter, which ships with Python, for a simple desktop window
- PySide or PyQt for a full desktop app
- Textual for a terminal UI
- BeeWare and Kivy when the target is mobile
- Streamlit, Gradio, or Dash for a data screen in a browser

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Add a quit choice that leaves the menu text unchanged.
3. Keep the change small enough to finish in one sitting.

## Where it sits

A data screen is often a thin UI over [data analysis](../08-data-analysis/README.md).
