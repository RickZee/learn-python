# Machine learning

A model that learns a pattern from examples and predicts a label or a number for a new example.

## Tools

- scikit-learn for classical models
- PyTorch for neural nets
- A held-out set of examples that the model does not train on

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Classify three points, and break a tie by choosing the label that comes first alphabetically.
3. Keep the change small enough to finish in one sitting.

## Where it sits

Hold back examples the model does not train on. The table work is [data analysis](../08-data-analysis/README.md).
