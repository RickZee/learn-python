# Packaging and distribution

A project other people can install, with its dependencies declared.

## Tools

- pyproject.toml as the project file
- uv or pip to install
- build and twine to publish to a package index

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Print the project name and the Python requirement, not only the dependency list.
3. Keep the change small enough to finish in one sitting.

## Where it sits

A package is a folder other code can [import](../../course/13-modules/01-imports-lesson.ipynb).
