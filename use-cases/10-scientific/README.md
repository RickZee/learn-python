# Scientific computing

Numbers, equations, and measurements: a slope, an integral, a simulation.

## Tools

- numpy for arrays
- scipy for numerical methods
- sympy when you want the algebra, not a decimal

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Estimate the slope at a second point and print which slope is steeper.
3. Keep the change small enough to finish in one sitting.
