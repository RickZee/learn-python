# Web applications

Sites a browser opens: pages, forms, and accounts.

## Tools

- Django when the site has a database, accounts, and an admin
- Flask or FastAPI when you want a smaller app
- Jinja for HTML templates
- HTMX when a page should update without a heavy frontend

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Add a third URL that returns the text `missing` for an unknown page.
3. Keep the change small enough to finish in one sitting.

## Where it sits

A page that calls your own code belongs with [services](../04-services/README.md).
