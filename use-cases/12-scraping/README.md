# Web scraping

Reading a page and pulling out the fields you need. Respect the site's terms and robots.txt. Prefer an API when one exists.

## Tools

- httpx or requests for the download
- Beautiful Soup for HTML
- playwright when the page is built in the browser
- A delay between requests

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Collect the link addresses as well as the link text.
3. Keep the change small enough to finish in one sitting.

## Where it sits

Prefer an [API](../04-services/README.md) when the site offers one.
