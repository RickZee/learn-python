# Hardware, embedded, and IoT

Bytes on a wire, a sensor, or a board that runs a smaller Python.

## Tools

- struct to pack numbers into bytes
- pyserial for a serial port
- MicroPython or CircuitPython on a microcontroller
- gpiozero on a Raspberry Pi

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Pack a second temperature and show that the first bytes did not change.
3. Keep the change small enough to finish in one sitting.
