# Text and language

Search, tokens, and models that read or write text.

## Tools

- re for patterns
- spaCy for linguistic structure
- A transformer library when you need a model

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Count only the words longer than three letters.
3. Keep the change small enough to finish in one sitting.

## Where it sits

A text model is a [machine-learning](../09-machine-learning/README.md) project with text as the input.
