# Business and finance

Money, invoices, and ledgers. Binary floating point is the wrong tool for cents.

## Tools

- decimal.Decimal for money
- A database for the ledger
- Django or a service from the web and services folders for the product around it

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Add a tax rate with Decimal and print the total, not only the float mistake.
3. Keep the change small enough to finish in one sitting.
