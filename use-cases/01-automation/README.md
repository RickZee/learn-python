# Automation and scripting

Scripts that rename files, reshape a spreadsheet export, or repeat a chore you currently do by hand.

## Tools

- pathlib and shutil for files and folders
- csv for spreadsheet exports
- A scheduler outside Python, such as cron, when the script must run unattended

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Drop the header row as well as a column, and write only the rows whose amount is positive.
3. Keep the change small enough to finish in one sitting.
