# Command-line applications

Programs people run from a terminal, with flags, help text, and a useful exit code.

## Tools

- argparse in the standard library
- typer or click when the command has several subcommands
- rich for tables and progress

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Accept two flags, not one, and print a different line when the path is missing.
3. Keep the change small enough to finish in one sitting.
