# Specialized fields

Some fields have their own libraries. The lesson is DNA sequence content. The tools list is the map of the other fields.

## Tools

- Biopython for sequences
- geopandas and shapely for maps
- Qiskit for quantum circuits
- web3.py for Ethereum clients
- networkx for graphs
- Jupyter when the work is exploratory

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Count the Gs and the Cs separately, then print both fractions.
3. Keep the change small enough to finish in one sitting.
