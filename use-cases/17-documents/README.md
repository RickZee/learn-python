# Documents and office files

CSV, JSON, PDF, and spreadsheets that other tools already produce.

## Tools

- csv and json in the standard library
- openpyxl for Excel
- pypdf or reportlab for PDF

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Add a second column and round-trip two rows, not one list of one-column dicts.
3. Keep the change small enough to finish in one sitting.

## Where it sits
