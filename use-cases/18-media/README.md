# Images, audio, and video

Pixels, samples, and frames. Python calls libraries that do the heavy work.

## Tools

- Pillow for images
- OpenCV when you need vision
- The colorsys module, used below, for color math with no extra install

## Do this first

1. Open [01-lesson.ipynb](01-lesson.ipynb) and run it.
2. Blend red and blue halfway, then print that hue. The lesson already converts pure red.
3. Keep the change small enough to finish in one sitting.
