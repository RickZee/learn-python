# Solutions

Try first. Open a file here only after you have attempted the practice, exercise, or problem.

| Kind | Where |
| --- | --- |
| Practice answers | `solutions/course/...` and `solutions/patterns/...` as `.py` files mirroring the learner path |
| Challenge walkthroughs | `solutions/challenges/problems/NN-name.md` next to the `.py` |
| Project references | under `solutions/use-cases/` when present |
