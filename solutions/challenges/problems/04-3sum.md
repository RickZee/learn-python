# 04. 3Sum — walkthrough

## Recognize it
Find unique triplets that sum to zero. After sorting, fix one value and solve two-sum with two pointers on the remainder. Look-alike: Two Sum with indexes (hash map) — here uniqueness of values matters more than indexes.

## Brute force
Three nested loops and a set of sorted triplets: O(n³).

## Key insight
Sort first. For each index `i`, search `left`/`right` for a pair summing to `-nums[i]`. Skip duplicates on `i`, `left`, and `right` so each triplet appears once.

## Algorithm
1. Sort a copy.
2. For `i` in `0..n-3`, skip equal `ordered[i]`.
3. Two pointers `left=i+1`, `right=n-1`; move on sum vs 0; on hit, record and skip duplicates.
4. Return the list of triplets.

## Trace
`[-1,0,1,2,-1,-4]` sorted `[-4,-1,-1,0,1,2]`.

| i | val | pair finds |
|---|---|---|
| 0 | -4 | none |
| 1 | -1 | (-1,2), (0,1) |
| 2 | -1 | skipped duplicate |

## Complexity
O(n²) time after O(n log n) sort. O(1) extra aside from the answer (plus the sorted copy).

## Edge cases
Fewer than three numbers → `[]`. All zeros → `[[0,0,0]]`. No triplet → `[]`.
