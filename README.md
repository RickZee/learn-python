# Learn Python: understand how it works, then build with it

A free, notebook-first course for writing real Python — language, internals, algorithm patterns, challenges, and small projects — with an optional AI tutor that explains while you write the code.

[![CI](https://github.com/RickZee/learn-python/actions/workflows/ci.yml/badge.svg)](https://github.com/RickZee/learn-python/actions)
[![Open in GitHub Codespaces](https://img.shields.io/badge/Codespaces-Open-blue?logo=github)](https://codespaces.new/RickZee/learn-python)

## What you'll learn

- The Python language, from first programs through classes, files, tests, and concurrency
- How Python works underneath (objects, dicts, the GIL, and more)
- Algorithm patterns and timed challenges with walkthroughs
- Small real projects under `use-cases/`
- How to use an AI tutor so it explains and you write the code
