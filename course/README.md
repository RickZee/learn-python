# Course

Part 1 units are lesson and practice notebooks. Part 2 units also add an `exercise/` folder of real programs you run with pytest. Open lesson, then practice, then the exercise when there is one.

| [07-iteration](07-iteration/01-comprehensions-lesson.ipynb) | Comprehensions, generators, sorting | ~100 |
