# Facilitator guide

This page is for someone running a cohort.

Practice notebooks start with a warm-up, then the core task, then a stretch. Pair two learners on practice: one reads the hint, the other types, and they swap on the next function. Common misconceptions are the **Common mistake** cell in each lesson.

A practice notebook is solved by the file at the same relative path under `solutions/`, with `-practice` removed and `.py` instead of `.ipynb`. Open a key after the learner has tried. The concept order is [the ledger](../maintainers/concepts.md); `uv run pytest` checks it.

Unit order and minute estimates are on the [course README](../../course/README.md). A practice usually takes about as long as its lesson.
