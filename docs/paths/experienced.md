# Experienced path

For you if you already write another language. Plan on about 5–8 hours a week.

## Checklist

1. [Install](../get-started/install.md)
2. Skim [how lessons work](../get-started/how-lessons-work.md)
3. Take the [placement](placement.md) quiz on paper; open every unit you score 0
4. Move through the [course](../../course/README.md); spend longer where Python differs (names, dicts, iterators, packaging)
5. Treat [How Python works](../../internals/README.md) as a main section, not optional
6. Add [patterns](../../patterns/README.md) when you want timed-problem shape
7. Finish one [project](../../use-cases/README.md)

## What to skip

- Units you scored 1 on in [placement](placement.md) — still skim Check yourself when unsure
- Long warm-ups on syntax you already know — still run the Check yourself cells
- Repeating a Part 1 practice you can already pass cold

Writing your own code? Keep the [Style guide](../reference/style-guide.md) and [Dos and don'ts](../reference/dos-and-donts.md) open, and see [Resources](../reference/resources.md) for outside reading.

Use an AI tool as your tutor: see [Learning with an AI tutor](../guides/learning-with-ai.md).
