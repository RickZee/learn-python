# Builder path

For you if you want a working project soon. Plan on about 4–8 hours a week.

## Checklist

1. [Install](../get-started/install.md)
2. [First notebook](../get-started/first-notebook.md) so the harness feels familiar
3. Course units you need for your project (files, modules, errors, tests) via [course/](../../course/README.md)
4. Pick one [project](../../use-cases/README.md) and finish it before opening another
5. Use Build mode in [AI setup](../guides/ai-setup.md) while you ship the project

## What to skip

- The full challenges list (unless you also want timed practice)
- Every internals lesson — open the ones linked from the course topics you hit

Use an AI tool as your tutor: see [Learning with an AI tutor](../guides/learning-with-ai.md).
