# Challenges path

For you if you want timed problem practice and strong pattern recognition. Plan on about 6–10 hours a week for six weeks.

## Checklist

1. [Install](../get-started/install.md)
2. Read [Challenge practice](../guides/challenge-practice.md) for the method
3. Pattern lessons in [patterns/](../../patterns/README.md) alongside [How Python works](../../internals/README.md)
4. Work [challenges](../../challenges/README.md) in order; use walkthroughs only after a real attempt
5. One [timed session](../guides/timed-session.md) in week 5
6. One codebase round under `challenges/codebase-rounds/`

## Six-week outline

1. Patterns 01–07 + How Python works + question bank
2. Patterns 08–22 + finish linked internals
3. Problems 01–15
4. Problems 16–30
5. Problems 31–50 + one timed session + library checkout round
6. Problems 51–68 + rate limiter round

Details and links: [Challenge practice](../guides/challenge-practice.md).

## What to skip

- Building every `use-cases/` project (do one if you want a portfolio piece)
- Re-reading every Part 1 lesson you already know — jump to gaps

Use an AI tool as your tutor: see [Learning with an AI tutor](../guides/learning-with-ai.md).
