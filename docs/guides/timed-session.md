# A 45-minute timed session

Use one unseen problem from [the list](challenge-practice.md). Time the five blocks. Score yourself after, then write the date you will try the same problem again.

| Minutes | Block |
| --- | --- |
| 5 | Restate the problem and the edge cases out loud |
| 5 | Name the approach and its cost before you write code |
| 25 | Write the solution |
| 5 | Run the checks and fix what fails |
| 5 | State time and space, and answer one follow-up |

## Score

Give each row 0, 1, or 2.

| Skill | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Problem solving | No approach | An approach that works | The target cost, named before coding |
| Code quality | Does not run | Runs, hard to read | Names and structure you would ship |
| Verification | No checks | The examples only | Edge cases and a scale check |
| Communication | Silent | Narrates the code | Narrates choices and tradeoffs |
