# Challenge practice

A typical timed round is one or two medium problems in 35–45 minutes. Working code and a stated complexity matter more than a memorized answer.

## Method

1. Restate the problem and ask clarifying questions.
2. Name the pattern and a brute force, then the improved idea.
3. Code the improved idea. Say the complexity out loud.
4. Run examples and one edge case.
5. Only then open the walkthrough under `solutions/challenges/problems/`.
