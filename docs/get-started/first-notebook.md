# Open your first notebook

You already installed the project (or opened Codespaces). This page runs one lesson cell and one practice check.

## 1. Open the lesson

Open `course/00-start/01-first-program-lesson.ipynb`.

## 2. Choose the kernel

A [kernel](../reference/glossary.md) is the Python process the notebook talks to. Choose **Select Kernel → Python Environments → `.venv`** (the one inside this repo).

If `.venv` is missing from the list, go back to [Install](install.md) and run `uv sync` again.

## 3. Run a cell

Click the first code cell and run it (Shift+Enter, or the Run button). You should see printed output under the cell.

Skim **Why you'd use this** and **After this lesson you can** at the top so you know what the lesson is for.

## 4. Open the practice

Open `course/00-start/01-first-program-practice.ipynb`. Run the import cell, then look at a check line.

- A line that starts with ✓ passed.
- A failed check shows an error; read the last line first.
- Hints sit in collapsed `<details>` blocks. Open them in order only when stuck.

## Stuck? Ask the tutor

Set up an AI tool once, then ask it to explain — you still write the code. See [Learning with an AI tutor](../guides/learning-with-ai.md).
