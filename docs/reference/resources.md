# Resources

Outside material that pairs well with this course. Start with the official docs: they are free, accurate, and kept current.

## Official

| Resource | Use it for |
| --- | --- |
| [Python tutorial](https://docs.python.org/3/tutorial/) | The language walk-through from the Python project |
| [Language reference](https://docs.python.org/3/reference/) | Exact rules for syntax and the data model |
| [Library reference](https://docs.python.org/3/library/) | Every standard-library module, with examples |
| [HOWTO guides](https://docs.python.org/3/howto/) | Deep dives: sorting, logging, regex, descriptors |
| [Python FAQ](https://docs.python.org/3/faq/) | Short answers to common "why" questions |
| [Glossary](https://docs.python.org/3/glossary.html) | Official definitions of Python terms |
| [Python Developer's Guide](https://devguide.python.org/) | How CPython itself is built and changed |

## Style and standards (PEPs)

| PEP | Topic |
| --- | --- |
| [PEP 8](https://peps.python.org/pep-0008/) | Style guide for Python code |
| [PEP 20](https://peps.python.org/pep-0020/) | The Zen of Python (`import this`) |
| [PEP 257](https://peps.python.org/pep-0257/) | Docstring conventions |
| [PEP 484](https://peps.python.org/pep-0484/) | Type hints |
| [PEP 634](https://peps.python.org/pep-0634/) | Structural pattern matching (`match`) |

More: [index of all PEPs](https://peps.python.org/).

## Longer style guides

- [Google Python Style Guide](https://google.github.io/styleguide/pyguide.html): detailed, with reasons.
- [The Hitchhiker's Guide to Python](https://docs.python-guide.org/): project layout and tooling advice.

## Tools used in this repo

- [uv](https://docs.astral.sh/uv/): environments and installs.
- [Ruff](https://docs.astral.sh/ruff/): linter and formatter. Each rule has a page that explains it.
- [pytest](https://docs.pytest.org/): the test runner.
- [Python Tutor](https://pythontutor.com/): step through code and see objects and names drawn.

## Practice and books

- [Exercism Python track](https://exercism.org/tracks/python): mentored exercises.
- [Real Python](https://realpython.com/): articles and tutorials.
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/): free book for beginners.
- [Think Python](https://allendowney.github.io/ThinkPython/): free book on programming fundamentals.
- [Python Cookbook](https://www.oreilly.com/library/view/python-cookbook-3rd/9781449357337/): recipes for experienced learners.
- [Fluent Python](https://www.oreilly.com/library/view/fluent-python-2nd/9781492056348/): the data model and idiomatic code, for the deep end.
