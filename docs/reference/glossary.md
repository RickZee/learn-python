# Glossary

Shared words used across this repo. American spelling.

**section.** One of the five top-level areas: Course, How Python works, Patterns, Challenges, Projects.

**path.** Your route through the sections (beginner, experienced, challenges, or builder).

**unit.** A numbered folder such as `01-basics` or `03-sliding-window`.

**lesson.** A `*-lesson.ipynb` notebook that teaches one idea with a worked example.

**practice.** A `*-practice.ipynb` notebook where you replace stubs and run checks.

**exercise.** A Part 2 `.py` stub plus `test_*.py` files you run with pytest.

**project.** A small app under `use-cases/` that you build after reading its page.

**explore page.** A short `use-cases/` page that is not a full project.

**problem.** A challenge notebook under `challenges/problems/`.

**pattern.** An algorithm idea taught in `patterns/` on a sibling problem.

**Part 1.** Course units taught as lesson and practice notebooks.

**Part 2.** Course units that add an `exercise/` folder of real programs.

**the tutor.** An AI tool set up with this repo's tutor prompt so it explains and you write the code.

**Codespaces.** GitHub's browser IDE that builds this repo for you with no local install.

**terminal.** The text window where you type commands (Terminal on Mac, PowerShell or Command Prompt on Windows).

**repository (repo).** The project folder, usually cloned from GitHub.

**clone.** Copy a repository from GitHub onto your computer with `git clone`, or download it as a ZIP.

**virtual environment.** An isolated Python install for this project, here the `.venv` folder.

**uv.** The tool that creates `.venv`, installs packages, and runs commands inside that environment.

**kernel.** The Python process a notebook talks to. Pick the `.venv` kernel so `import pylearn` works.

**notebook.** A `.ipynb` file of cells you run one at a time.

**cell.** One block of Markdown or code in a notebook.

**package.** A reusable library you import, such as `pytest`.

**pytest.** The test runner used for Part 2 exercises, projects, and this repo's checks.

**PATH.** The list of folders your shell searches when you type a command name.

**PEP.** A Python Enhancement Proposal: a numbered document that describes a Python feature or convention. PEP 8 is the style guide.

**linter.** A tool that reads your code without running it and flags style problems and likely bugs. This repo uses `ruff`.
